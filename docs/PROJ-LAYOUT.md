# SigNoz — Project Layout

Navigable map of the repository. SigNoz is a Go backend (`cmd/` + `pkg/`) and a
React/TypeScript frontend (`frontend/`) shipped as a single container image; the
fork is MIT-only and the backend is the community server binary.

```
signoz/
├── cmd/                          # Cobra CLI entrypoints
│   ├── root.go                   #   Root command + subcommand registration
│   ├── config.go                 #   YAML config loading/validation
│   ├── generate.go               #   Config/OpenAPI generation helpers
│   ├── metastore.go              #   Metastore command wiring
│   └── community/                #   Community server binary (main.go, server.go)
├── pkg/                          # Go backend packages → [layout/pkg.md](layout/pkg.md)
│   ├── apiserver/                #   HTTP server + per-domain route registration
│   ├── modules/                  #   29 domain modules (interface + impl<name>/)
│   ├── sqlstore/                 #   Metastore: SQLite (default) or Postgres via bun
│   ├── telemetrystore/           #   ClickHouse telemetry store
│   ├── sqlmigration/             #   135 metastore migrations numbered 000–135 (010 absent)
│   ├── telemetryschema/          #   ClickHouse signal schemas
│   ├── authn/ authz/ identn/     #   Identity, permission, and resolver stack
│   └── ...                       #   query builders, plugins, alerting, cache
├── frontend/                     # React 18 + TypeScript + Vite UI → [layout/frontend.md](layout/frontend.md)
├── docs/                         # Documentation
│   ├── api/openapi.yml           #   Generated HTTP API contract (consumed by orval)
│   ├── contributing/             #   Development, tests, Go and PromQL guides
│   ├── plugins/README.md         #   Plugin catalog + security model
│   ├── noizu/                    #   Fork-specific design docs
│   └── img/, readme-assets/      #   Doc images
├── conf/                         # Runtime config: example.yaml, plugins.example.yaml
├── deploy/                       # install.sh, MIGRATION.md, README.md
├── plugins/                      # Static plugin catalog served at /api/v1/plugins
├── grammar/                      # ANTLR grammars (filter, having, trace operator)
├── templates/                    # Alertmanager + email notification templates
├── scripts/                      # clickhouse, grammar, promqltestcorpus, semconv generators
├── tests/                        # Python integration/e2e suites, fixtures, seeder
├── .github/workflows/            # CI, release, and noizu-image publishing
├── .claude/                      # Agent rules, skills, and worktrees (not shipped)
├── .devenv/                      # Local dev container definitions
├── Makefile                      # Build, test, run, docker targets
├── go.mod / go.sum               # Go module github.com/SigNoz/signoz (go 1.25.7)
├── README.md                     # Start here
└── CHANGELOG.md                  # Dated work log (fork)
```

## Key files requiring setup

| File | Action |
|------|--------|
| `conf/example.yaml` | Reference for every runtime config section; pass your own file with `--config` |
| `conf/plugins.example.yaml` | Plugin catalog settings (`dir`, `enabled`) |
| `frontend/example.env` | Copy to `frontend/.env` for local UI development |
| `.devenv/` | Backing services (ClickHouse, Postgres, OTel collector) for local dev |
| `Makefile` | `go-run-community`, `go-build-community`, `js-build`, `devenv-up` |

## Notes

- `docs/api/openapi.yml` is generated by `cmd/openapi.go`, not hand-edited; the
  frontend API client under `frontend/src/api/` is generated from it by orval.
- Generated trees (`frontend/src/api`, `frontend/src/schemas/generated`,
  `pkg/semconv`) must not be hand-modified.
- `frontend/` has its own `CLAUDE.md`/`AGENTS.md` and `.claude/` rules for UI work.
